⬇ Завантажити для Windows

Як почати

Три кроки — і ви на сервері.

Встановіть лаунчер

Завантажте DodoShield-Launcher-setup.exe і запустіть. Windows може попередити про невідомого видавця — натисніть «Докладніше → Виконати все одно».

Увійдіть в акаунт

Натисніть «Увійти через Microsoft» і авторизуйтесь акаунтом, на якому куплено Minecraft: Java Edition.

Оберіть збірку та грайте

Виберіть вкладку Immortal або Fabulously Optimized і натисніть «Грати». Перший запуск завантажує кілька гігабайтів — далі все відкривається за секунди.
